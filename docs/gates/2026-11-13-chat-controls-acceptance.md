# 会话控制验收

本轮在 macOS 验证会话控制的源码与自动化路径。使用合成工单、临时状态库、模拟 MCP 客户端和隔离的本机 IPC。真实工单写入及 Windows 实机均待验。

| 路径 | 证据 |
|---|---|
| 工具发现 | 编译后的 CLI 通过 stdio 完成 MCP 握手，发现 36 个工具。 |
| 操作确认 | 测试覆盖确认、拒绝、取消、客户端缺少表单、预览变化及重复提交。 |
| Codex 原生确认协议 | 使用实际 Codex CLI 0.159.2 的 App Server、独立临时配置和合成 IPC。客户端收到原生表单请求；拒绝或取消均无提交，接受恰好提交一次，重放旧预览被拒绝。未调用模型或连接真实 Linear，未进行 GUI 人工点击。 |
| 运行和配置 | 引擎测试覆盖派发、接续、停止、重试、待验收、完成、方案收口及绑定与设置复核。 |
| 诊断 | 使用替身核对连接、更新和系统状态的输出，避免向会话返回原始诊断或凭据。 |
| 回归 | Rust 1,166 项与前端 1,307 项通过，前端构建、格式、Clippy、lint 与公开仓库扫描通过。 |

待实机：Claude Code 的人工确认、真实测试需求的状态读回，以及 Windows 安装和操作。发布工作流核验安装包，不代替真机验收。
