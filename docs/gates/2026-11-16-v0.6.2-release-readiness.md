# v0.6.2：工作流修正与发布前本机验证

## 本次行为

版本从 0.6.1 顺延至 0.6.2，包含已在本地收口的五项修正：

- 派发与验收预览显示有效期及明确的到期反馈，五种现有语言完整；相同 fingerprint 的新预览重新计时。提交中保留真实进度，刷新后仍需人工核对并确认。
- 独立验证在删除临时源码前保存固定目录内的报告和附件，生成大小与 SHA-256 索引；保存失败保持受阻，不能借附件缺失宣称通过。
- 显式 Codex 聊天确认配置不再被误报为未知键，不改变默认值、权限或原生确认边界。
- 返修关联被轮询读到时保持已打开的审核框及原令牌，不增加历史运行的新派发入口。
- 有完整报告的 Failed 或 Blocked 验证可经正常预览和确认退回诊断或修复；原推荐结论、状态、报告及证据保持，后续仍需新开发会话、新交付和独立复验。

发布复核另发现键盘焦点遗漏：审核入口随轮询消失后，取消对话框会丢失可聚焦目标。最小修复复用现有 `useFocusReturn`，在入口消失时回到仍有效的打开前焦点或页面标题；入口仍在时继续使用 Radix 默认恢复。没有新增文案、命令、权限或绕过确认的接口。
