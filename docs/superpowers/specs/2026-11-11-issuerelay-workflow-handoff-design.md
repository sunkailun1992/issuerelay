# 多入口执行、模型目录与持久交接设计

本轮将 IssueRelay 的定位落到三个能力：从主控会话登记需求上下文和执行偏好；按实际执行器能力选择模型；在额度或其他中断后将工作交给一个明确选择的新会话。Linear 仍负责需求与验收状态，IssueRelay 负责本机调度与运行记录，编码与复核由 Codex 或 Claude Code 完成。

## 取舍

保留现有 CLI 执行、Linear 触发与本地 SQLite，在当前架构增加结构化上下文与交接。改用统一聊天服务可以提供更深的原生界面接管，但需要另建会话生命周期和 Claude 接口；全自动额度切换也会把部分未知错误变成第二次执行。两项均不作为本轮交付前提。Codex App Server 仅用于已验证的原生模型目录查询，不创建推理会话。

## 执行选择

按需求持久保存入口执行器、显式选择、原始需求、确认范围、验收条件和来源引用。MCP 登记通过客户端信息识别明确支持的 Codex / Claude 名称；未知客户端保留未知，来源只作路由提示。用户在准备需求时先登记上下文，再按原流程设接单标签。登记带 revision 并检测并发覆盖，不写 Linear、不打标签、不触发轮询或运行。

按编号登记和查询时，先在当前 Linear 连接中解析内部任务身份，避免不同工作区的相同编号串用。单次运行把启动时的需求上下文保存为快照，之后修改需求不会改写旧运行的依据。

执行者优先级：需求显式选择 → 项目绑定显式配置 → 入口执行器 → 软件默认。所有排队、就绪检查和真正启动共用这一决策；进行中的运行不改变执行器。切换提供者时不能把另一个提供者的模型或专属力度当成有效配置。

## 模型与力度

Codex 按已安装 CLI 的 `model/list` 更新目录，显示原生默认和推荐项，保留用户自定义输入；失败时显示来源和内置备选。Claude 提供随 CLI 解析的官方别名，包括 `fable`、`opus`、`sonnet`。保留用户已有配置，刷新目录不覆盖已选模型。Codex `ultra` 与 Claude `Ultracode` 分开，后者用独立 Claude 工作流设置。显式的 Claude 力度同时正确处理 `CLAUDE_CODE_EFFORT_LEVEL` 优先级，不改用户全局环境。

## 检查点、中断与交接

本地运行元数据按 job 持久保存执行来源、最新结构化检查点、已确认额度事件及 Git 现场。宿主在运行前后保存已知事实；模型在关键阶段输出专用的有界 JSON 记录，宿主收到时即落盘，标明模型自述验证与实际测试证据的区别。检查点只记录源文件引用和摘要，不自动复制整份会话、Wiki 或凭据；外来文本仍是数据。

仅将可明确识别的执行器额度事件分类为额度中断；不知道恢复时间时留空。旧执行器退出后，使用者可以选择由 Codex 或 Claude 新会话接手，领取同一工作目录的本机交接保留权。保留期间后台调度不会抢占同目录；领取与释放不启动执行者、不修改 Linear。交接记录提供共同需求、代码现场、验证结果与剩余事项，可从 MCP 或面板读取。跨执行器接手启动新会话，不使用旧 session ID，也不根据不确定的额度报错静默换提供者。

独立复核由新的会话读取同一证据包，按验收条件检查实际 diff 与验证结果；产品提供独立复核提示与入口，本轮不把这一入口描述为已经自动执行复核或业务验收。

## 双端查询与 Wiki

Codex 和 Claude 都可连接同一台电脑上的 IssueRelay MCP。按本机运行 ID 可以离线查；按 Linear 编号查的是当前工作区的最近一次运行。结果包含后台状态、执行者、结果、检查点、交接及 Wiki 回执；MCP 查询不会重开原聊天，也不会为外部人工续作编造进度。

设有 Wiki 目录时，IssueRelay 提供归档材料，主控会话按目标 Wiki 自身规则写入需求拆解、实现结果、实际测试和经过筛选的关键决定。当前 Wiki 根及现存页面对应的回执是面板确认完成的前提；领取写入交接会清除旧回执。回执检查不能替代对 Git 推送的验证。未配置 Wiki 时仍保存本机运行记录。

## 接口与验证

保留现有五个 MCP 工具与旧 IPC 调用。新增上下文读写、运行查询、交接读取/领取/释放及回执登记；MCP/CLI 仍不能标记 Done、重试或取消运行。领取用独立 ID，迟到的释放不会清除后来取得的保留。数据库升级至 schema 3，旧调度器不能打开新数据库而绕过保留。旧 session resume 与旧绑定行为继续兼容。以合成需求、临时 SQLite、假执行器和协议测试验证路由、检查点、额度证据、目录单写者及面板；真实订阅额度耗尽、双端账号条件与 Windows 实机单列验证，不用测试夹具代替。
