# 多入口与交接升级验证计划

设计见 [多入口执行、模型目录与持久交接设计](../specs/2026-11-11-issuerelay-workflow-handoff-design.md)。本文件只记录仓库实现与验收范围，不是 Linear 任务或派工指令。

| 变更面 | 实现与验证 |
|---|---|
| 来源与路由 | 本机上下文 CAS 写入；独立测试显式、绑定、入口、默认、未知来源；就绪判断与真正启动使用相同执行者 |
| 执行配置 | 保持旧配置可读；补 Codex Ultra、Claude Ultracode；验证实际参数和环境优先级，模型目录失败不清空用户选择 |
| 运行记录 | 执行中保存有界结构化检查点，区分模型自述与已知 Git 状态；测试退出、重启读回、过期写者和不可信事件 |
| 额度与交接 | 明确额度事件保持等待；没有证据的错误保持原失败语义；领取/释放无派工副作用；旧运行和同目录互斥仍生效 |
| MCP 与面板 | 两个客户端查同一个本机运行；按编号解析当前 Linear 身份、按 ID 可离线；验证工具清单、错误返回、权限、五语言和复核提示 |
| Wiki 与迁移 | 验证有效回执、换根/删除/领取后拒绝旧回执；未设置 Wiki 继续只保留本地；旧版本不得打开 schema 3 绕过目录保留 |
| 交付 | 完成构建、Rust 格式/静态检查/测试、前端检查/测试及严格敏感信息扫描；独立代码审查；标明未做的实机与公开发版 |
